How it started

Annual leave

First app was built on holiday.

Reports took hours. Screenshots every week. Slides rebuilt from scratch. Nothing from Impect on its own. Comparing players was the worst bit. On leave I built Player Comparison — profiles, radars, a deck you can send to staff.

That was the first tool. Pre-match, set pieces, scouts, recruitment, strategy — all because I got sick of rebuilding the same report every week.

Why we built it

Everything was manual. Hours every week. Nothing pulled in on its own.

01 Reports ate the week

Pre-match decks, player slides, staff presentations — built by hand every time. Crop a screenshot, copy stats into PowerPoint, fix the layout. Same job, week after week.

  • No automatic pull from Impect
  • Hours before anything reached the room
02 Comparing players was a mess

Screenshots in group chats. Stats in different tabs. No clean way to put two players side by side and send it on.

  • Profiles and radars in one view
  • A deck you can actually send
03 Work lived all over the place

Pre-match here, scout list there, recruitment on another drive. Half the job was finding the latest file. The other half was rebuilding slides.

  • Match prep, scouts, recruitment, strategy
  • Same login, same left rail

One site. Data comes in. You don't start from a blank slide every time.

Performance analysis

Analysis tab

Impect data in. Reports build themselves. Roughly 20 hours a week back.

  • API, not screenshots

    Match numbers come straight from Impect. No copying stats into PowerPoint every Monday.

  • Automated packs

    Pre-match, post-match, set pieces, blocks — pick the game, the report fills. Same numbers the coaches see in the room.

  • Clear targets

    Gold / silver / bronze aims on the board. Live progress next to them, so we know what to fix before the next block.

20+ hours a week saved on analysis reports alone

Blocks analysis

Season in nine blocks

Five games at a time. Targets on the board. Results fill in live.

  • Block 1–9

    Every league game sits in a five-game block. Results colour win / draw / loss as soon as the data lands.

  • Gold · silver · bronze

    Set the points and clean-sheet aim for the block. Progress bars update from the API — no manual scoreboard.

  • What to fix next

    Coaches see where the block sits against target before the next five. Clear number, clear ask.

9 blocks · live points & clean sheets vs target — no spreadsheet rebuild

Recruitment

Recruitment tab

Find players from the data. Track them on one board. Plan the squad.

  • API finds the names

    Who To Scout ranks players by league and position from Impect — how we play, not a gut-feel shortlist.

  • One tracking board

    Pipelines: data → video → live. The whole group sees the same cards, notes, and status.

  • Squad design

    Scoutable teams by club. Squad planner for current and shadow XIs. Gaps by position, clear.

1st app on leave was Player Comparison — recruitment still starts there

Who to scout

From the Impect API

Ranked lists by league and position. Not a folder of screenshots.

  • Pick the filter

    League, position, age, minutes, height. Weights for how we want that role to play.

  • Top of the pool

    Best profile scores sit at the top. See club, age, and where they sit in the pool.

  • Link to coverage

    Names already live / video / reported from Fixture Planner show up — so you know who's left to watch.

Future developments

Medical, sports science and GPS in the same hub.

01 Medical

Injury status, return-to-play and notes next to availability — not a separate folder staff have to chase.

  • One view for who's fit
  • History that stays with the player
02 Sports science

Load, recovery and readiness in the same login as match and recruitment work.

  • Same language across staff
  • Less double entry
03 GPS data

Training and match GPS pulled in so distance, intensity and session load sit beside the football picture.

  • Automatic where we can
  • Usable in the room, not only on a laptop
